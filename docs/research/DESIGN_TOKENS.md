## Font Sizes (observed)
- Hero title: ~200px+ (VC Nudge Black)
- Section headings "WORK", "WHY ME": ~150-180px
- Bio text: ~32-40px uppercase  
- Labels/tags: ~12-14px mono
- Nav links: ~14px

## Spacing
- Section padding: ~80-100px horizontal
- Component gap: 24-48px

## Borders / Radius
- Buttons: rounded corners ~8px or pill shape
- Client logo cards: rounded ~16px, border 1px rgba(white, 0.2)

## Smooth Scroll
- Library: Lenis v1.3.17-framer
- Config: default (ease easing, ~1.2 lerp)
